> **Version**: v3.0-game

## Vision

Transform `norbu.dev` from a static tech blog into an immersive, **cyber-themed puzzle game** built around the Axiom universe. Players navigate a mysterious distributed system — interacting with terminals, deciphering ciphers, tracing network anomalies, and uncovering the nature of Spectre.

The aesthetic is operator-grade: dark, neon-lit, pixel-rendered. The tone is the CODEX — authoritative, quiet, unsettling.
